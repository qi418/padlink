# PadLink 使用教程（配对 + 验证 + 日常使用）

## 一、第一次配对（只做一次）

方式 A（推荐）：平板 App 内配对
1. iPhone：设置 → 蓝牙 页面**保持打开**（让 iPhone 可被发现）。
2. 平板：打开 PadLink → 配对引导页 → 开始扫描 → 列表出现你的 iPhone → 点击配对。
3. 两端都会弹出配对确认，**确认码必须一致**，都点确认。

方式 B：系统设置配对
1. iPhone：设置 → 蓝牙 保持打开。
2. 平板：设置 → 蓝牙 → 搜索 → 点 iPhone 名配对，两端确认。

## 二、打开"共享系统通知"（关键一步！漏了收不到通知）

1. iPhone：设置 → 蓝牙 → 找到已配对设备（名字可能是 PadLink 或平板的蓝牙名）。
2. 点设备右侧 ⓘ → 打开 **"共享系统通知"** 开关。

## 三、验证链路（一期验收标准）

1. 平板 PadLink 状态页显示"已连接"。
2. 让朋友给你的微信发一条消息（或自己给自己发）。
3. 1-3 秒内平板应弹出/显示该通知（标题+正文）。
4. 测试全部 App：微信、QQ、短信、其他任意 App 的通知都应流转。
5. 锁屏 iPhone 再试一次（锁屏也必须能收到）。

## 四、日常使用

- **看通知**：平板下拉通知栏，或打开 PadLink 通知中心查看历史（最多 200 条）。
- **回复**：点通知 → 平板直接打开微信/QQ（平板需登录同账号）手动回复。
- **动作按钮**：部分 App 通知带"标记已读/回复/清除"按钮（来自 iOS 的通知动作），点击会回传 iPhone 执行。
- **断线自动重连**：iPhone 短暂离开蓝牙范围回来后自动恢复，无需操作。
- **黑名单**：PadLink 设置里可屏蔽不想显示的应用。

## 五、可选功能：自动连 iPhone 热点（默认关闭）

设置 → "自动连 iPhone 热点"：一期预留开关，默认关闭。平板已有网络（Oppo 手机共享），一般无需开启。

## 六、FAQ 与已知限制

1. **iPhone 重启后**：平板会自动重连；PadLinkHelper 需手动打开一次；若只是收通知，不打开也能用。
2. **收不到某 App 的通知**：检查 iPhone 上该 App 通知是否开启（设置 → 通知）；检查"共享系统通知"开关。
3. **通知延迟**：iPhone 锁屏下延迟通常 <5 秒；平板休眠时由安卓 Doze 决定，建议平板按安装教程锁后台。
4. **不能转发图片**：ANCS 只提供标题/正文/动作，图片附件无法获取（iOS 限制）。
5. **不能一键已读所有通知**：iOS 只开放单条通知的一两个动作，无法批量操作。
6. **点击平板通知不能远程打开 iPhone App**：只能打开平板本地的对应 App。
7. **耗电**：iPhone 端约 1-3%/天；平板端 BLE 连接功耗很低。
8. **平板重启后**：PadLink 若未开机自启，打开一次即可（按安装教程开启自启动可免手动）。

> 任何一步卡住，先查《排障指南.md》（按现象定位到条目）；仍解决不了，用排障指南第 9 条的 adb 命令抓日志发给我。
