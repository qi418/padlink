# PadLink 平板端安装教程（Oppo Pad 4 Pro）

## 一、获取 APK

1. 把本工程推送到你的 GitHub 仓库（公开或私有均可）。
2. 打开仓库 → **Actions** 页 → 左侧 **Build Android APK** → **Run workflow** → 绿色按钮运行。
3. 约 3-6 分钟后，进入该次运行 → 底部 **Artifacts** → 下载 **PadLink-APK**（zip）。
4. 解压得到 `PadLink-release.apk`，发送到平板（微信文件传输助手 / 网盘 / 数据线均可）。

## 二、安装

1. 平板打开 APK，允许"安装未知来源应用"。
2. 安装完成后**先不要急着配对**，按下面第 3 步把权限配齐。

## 三、权限与后台配置（ColorOS 15，必须逐项完成）

1. **通知权限**：设置 → 应用 → PadLink → 通知 → 全部允许（App 首次启动也会弹窗申请）。
2. **蓝牙与附近设备**：设置 → 应用 → PadLink → 权限 → 允许"附近的设备"（即蓝牙）；旧版本系统还需允许"位置信息"。
3. **自启动**：手机管家 → 应用管理 → 自启动管理 → PadLink → 开启。
4. **电池**：设置 → 电池 → 更多设置 → 应用耗电管理 → PadLink → **允许后台运行 + 允许完全后台行为**。
5. **后台管理**：最近任务列表长按 PadLink 卡片 → 锁定（出现锁图标），防止划掉。
6. 打开 PadLink，首页若提示"前台服务未运行"，点启动。

> 说明：PadLink 使用前台服务常驻，任务栏会有一条低优先级常驻通知，这是安卓强制要求，请勿关闭该通知渠道。

## 四、验证是否装好

- 打开 PadLink → 状态页能看到"蓝牙已开启"，并进入配对引导页即算安装成功。
- 下一步按《使用教程》与 iPhone 配对。
